## 🚀 Qanday ishlatish

### 1. Repository klonlash
```bash
git clone https://github.com/maxliyoibragimova838-prog/boburjon-portfolio.git
cd boburjon-portfolio
```

### 2. Brauzerda ochish
`index.html` faylni brauzerda oching yoki:

```bash
# Python bilan
python -m http.server 8000

# Node.js bilan
npx http-server
```

### 3. Kontakt ma'lumotlarini yangilash

`index.html` faylni ochib, quyidagi bo'limlarni o'zingizga mos qilib o'zgartiring:

```html
<!-- Contact Section -->
<div class="contact-item">
    <i class="fas fa-envelope"></i>
    <p>boburjon@example.com</p> <!-- Email o'zgartiring -->
</div>
```
